## Tartalmi áttekintés

1. **Alapkiírás:** `print()`, `sep`, `end`, `\n`, `\t`, idézőjelek, perjel, többsoros szöveg.
2. **Szövegformázás:** f-string, balra/jobbra/középre igazítás, mezőszélesség, kitöltő karakter, rövidítés.
3. **Számformázás:** tizedesjegyek, nullával feltöltés, ezres csoportosítás, százalék, előjel, tudományos jelölés.
4. **Összetett kimenetek:** igazított táblázatok, fejléc, keretek, ciklusos kiírás, feltételes szöveg, karakterdiagram.
5. **Kiegészítő haladó témák:** ANSI-színek, sorfrissítés, dátumformázás és konzolos menük.

## Módszertan

A tanuló először azonosítja a követelményt („tabulátorral elválasztva”, „két tizedesjeggyel”, „oszlopokba rendezve”), utána kiválasztja az ahhoz szükséges Python-eszközt, végül ellenőrzi a mintakimenetet.

A feladatok **egyszerű változókra, listákra, ciklusokra és feltételekre** épülnek. Objektumorientált programozás, külső csomag, HTML és adatbázis nem szükséges.

Az **1–4. szint** alap- és érettségi gyakorlatra szánt anyag. Az **5. szint** érdeklődőknek ajánlott kiegészítő.

**Javasolt feldolgozás:** rövid bemutató → indokolt kódválasztás → önálló feladatmegoldás → kimenetellenőrzés.
